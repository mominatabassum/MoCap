🎓 **Final Year Project – Real-Time Motion Capture System**
 -  We are a group of three Electrical Engineering students from NUST SEECS. For our Final Year Project, we developed a real-time motion capture system using ICM-20498 IMU sensors and ESP32 microcontrollers to animate a 3D character in Blender.

**🔧 Key Features**
  1. Real-time tracking of full-body movements
  2. Wireless data transmission using ESP32
  3. Sensor fusion for accurate orientation (yaw, pitch, roll)
  4. Live character animation in Blender via UDP socket

**🛠️ Technologies Used**
  1. ICM-20498 IMU Sensors
  2. ESP32 for wireless sensor interfacing
  3. Embedded C / Arduino for firmware
  4. Python for data parsing and UDP communication
  5. Blender (Python API) for character animation
